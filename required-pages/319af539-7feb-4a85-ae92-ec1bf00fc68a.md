# Overview

[{$pagename}] are [Platform Variables] that are based on your current context within [{$applicationname}].

[{$pagename}] are  [Platform Variables] that require __user or page__ context Like:

- what page you are on: [{$pagename}]
- Your User Name: [{$username}]
- etc.

[{$pagename}] are provided from [Plugins]

## Available context variables

%%table-striped
|| Variable || Expands to || Example use ||
| `${pagename}` | Current page's display __name__ (e.g. `2026 trip west`) | headings, prose, plugin params |
| `${pageslug}` | Current page's __slug__ — URL/keyword form (e.g. `2026-trip-west`) | keyword-matching plugin params |
| `${username}` | Signed-in user's username | greetings, personal filters |
/%

Both the `${...}` (dollar-brace) and `[{$...}]` forms are supported; the `${...}` form is the one to use __inside plugin parameters__, since it is expanded before the plugin runs.

> __`${pageslug}` vs `current`:__ `${pageslug}` always gives the slug form. The `current` __parameter shortcut__ (see [Plugin Parameter Shortcuts]) is smarter for keyword-scoped plugins — it tries the page name *and* slug and uses whichever has content. Prefer `current` for self-scoping media/search; reach for `${pageslug}` only when you specifically need the slug form.
