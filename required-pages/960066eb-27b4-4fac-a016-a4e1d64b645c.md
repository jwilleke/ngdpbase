# Markdown as we use it

Pages here are written in Markdown, the plain-text format where `# Title` makes a heading and `- item` makes a bullet. We follow [CommonMark](https://commonmark.org/), the standard version of Markdown, and add a few things of our own. Together this is called __NGDP-Compatible Markdown__, or __NCM__.

This page is the reference for how to write a page. It has two parts:

- __What works:__ everything standard Markdown allows, plus our additions.
- __How we write it:__ the style we use on our own pages. Please follow it on yours, so pages look the same everywhere.

## What works

### Standard Markdown

All of it: headings, paragraphs, bold and italic, links, images, quotes, lists, code, horizontal lines, and some HTML.

### Our additions

- __Line breaks:__ a new line in what you type is a new line on the page. To break a line without starting a new one in the editor, type `\\`. Typing `<br>` is refused when you save. See [Markdown Cheat Sheet].
- __Tables:__ `|| Header || Header ||` then `| cell | cell |` rows. See [Table Examples] and [JSPWiki Table Functionality].
- __Strikethrough:__ `~~text~~`.
- __Subscript and superscript:__ `H~2~O` and `X^2^`, with no spaces between the marks. For longer text use `%%sub text/%` and `%%sup text/%`.
- __Footnotes:__ `a claim[^1]` in the text and `[^1]: the note` on its own line. See [Using FootnotesPlugin].
- __Emoji:__ `:smile:` and other shortcodes. See [Using Emoji].
- __Links to pages:__ `[Page Name]`, or `[Text to show|Page Name]`. Link to a heading on a page with `[Text|Page Name#section=Heading Text]`. See [Using Links].
- __Plugins:__ `[{PluginName param='value'}]` inserts live content, such as a list of recent changes. See [Plugin].
- __Variables:__ `[{$pagename}]` inserts the page's name; there are many others. See [System Variables].
- __Boxes and styling:__ `%%information … /%` makes an information box; `%%(color:red) text/%` styles a few words. See [Page Content].

### Good to know

- `foo_bar_baz` stays as written. Underscores inside a word never make italics; use `*italic*`.
- Anything inside code, `` `like this` `` or a code block, is shown exactly as typed. Plugins, links and variables inside code don't run.
- Headings can be linked to. A heading that appears twice on a page gets `-1` added for the second one, so link to the first.

### Doesn't work

- __Checkboxes__ (`- [ ]`, `- [x]`): the brackets are read as a page link.
- __Definition lists__, `==highlight==`, and `{#my-id}` after a heading: these show as plain text.
- __Old JSPWiki formatting__, `!!!` headings and `*` / `**` / `#` at the start of a line: converted when a page is imported, not when it is shown. Older pages that still have `**` bullets are being converted.

## How we write it

- __Headings:__ `#` for the page title, `##` for sections, `###` below that, each followed by a space.
- __Bold and italic:__ `__bold__` and `*italic*`.
- __Bullets:__ a hyphen and a space, `- item`. Don't use `*` or `+`; switching between them in the middle of a list starts a new list.
- __Bullets under bullets:__ indent 2 spaces for each level.
- __Numbered steps:__ a bullet with the number and no dot: `- 1 First step`, `- 2 Second step`.
- __Links:__ `[Page Name]` or `[Text|Page Name]` for pages here, and `[Text|https://example.com]` for other sites.
- __Tables:__ `|| Header ||` and `| cell |` rows.
- __Code:__ three backticks and the language, then the code, then three backticks:

````text
```bash
./server.sh status
```
````

- __Dividing lines:__ `---` on its own line, with a blank line above it. Without the blank line, the text above turns into a heading.
- __Quotes:__ `>` at the start of each line. A blank line between two groups makes two separate quotes.
- __HTML boxes:__ put `<div …>` and `</div>` on lines of their own, with a blank line above and below the text inside, so the formatting inside works.
- __A bullet that starts with `>`__ (such as `- \>10 mg`): put a backslash before the `>`, or it turns into a quote.
