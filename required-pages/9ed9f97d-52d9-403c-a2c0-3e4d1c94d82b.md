# Demo Feature Tour

A short tour of what page content can do. Open **Edit** on this page to see the markup behind every section below — reading the source is the fastest way to learn the syntax.

## Headings and links

Every heading on a rendered page gets an `id`, so any heading can be linked to directly. That is how [this link|#tables] jumps straight to the table section further down.

Links to other pages use bracket syntax:

```text
[Demo Sandbox]                     a page
[scribble here|Demo Sandbox]       a page, your own wording
[Demo Sandbox#scratch-area]        a section of another page
```

Full detail in [Using Links].

## Code blocks

Fenced blocks keep their contents verbatim — no link parsing, no formatting:

```js
function greet(name) {
  return `Hello, ${name}`;
}
```

## Style blocks

Wrap content in `%%class … /%` to put it in a styled container:

%%card p-3 mb-3
This paragraph is inside a card. Multiple space-separated classes all land on the same element.
/%

## Plugins

Plugins run at render time and drop live content into a page. This one lists recent changes:

[{RecentChangesPlugin max='5'}]

Others cover images, galleries, calendars, indexes, search results, page counts and more — every plugin has its own `Using …` documentation page.

## Versioning

Every save creates a new version. Open **History** on any page to see the list, compare two versions, or restore an earlier one. Restoring does not erase history — it adds a new version whose content matches the old one, so nothing is ever actually lost.
