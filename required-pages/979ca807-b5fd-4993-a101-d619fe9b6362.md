# Importing Files

The [Import|/import] page brings files from outside into [{$applicationname}]: documents that become pages, files for the site's file store, or records an add-on keeps, such as health records.

## What you can import into

The page lists only what your account may add to. If you may create pages, you see __Pages__. If you may upload files, you see __Files__. Add-ons can add their own, such as __Health records__. Each one decides for itself whether you may use it, with the same rules that apply anywhere else on the site.

If the page says there is nothing you can import into, your account cannot add any of these. Ask an administrator if you think it should.

A link from another page can open the Import page with one choice already picked, for example from your health records.

## How to import

- 1 Choose what to import into.
- 2 Choose one or more files, or a zip of them. A zip is unpacked for you; system files inside it, such as `.DS_Store`, are skipped.
- 3 If you chose one file, you can name what it becomes. The name starts as the file's own; keep it, or type a better one, such as __Bank statement October__ instead of `export_20261029.csv`. For a page, the name is its title. For a file, keep its ending (such as `.csv`). A zip, or several files at once, keep their own names.
- 4 Where it is offered, choose what happens to the original file: not kept, a note on what you imported saying where it came from, or a copy kept beside it.
- 5 Select __Import__.

The import runs in the background. You can leave the page. While it runs, the page shows how far it has got; when you come back, each file's result is under __Your recent imports__: when it was imported, its name (a name you gave it, with the file's own name beside it), the result, and what it went into, with a link to open what was created where you may open it. Times are shown in your own time zone.

## What each result means

%%table-striped
|| Result || Meaning ||
| Imported | Everything in the file was added |
| Partly imported | Some of it was added; the message says what was left out |
| Already imported, unchanged | You imported this same file here before, so it was skipped |
| Already here | What the file holds is already on the site, for example a page with the same title |
| Skipped (not content) | A system file, such as one a computer adds to a zip |
| Could not be read | The file is not in a format this choice can read |
| Not allowed | Your account may not add this, or the name you gave it cannot be used; the message says which |
| Failed | Something went wrong; the message says what |
/%

## Good to know

- Importing the same file again does not add it twice, even under another name.
- A name you give must not be taken already: if a page with that title, or a file with that name, is already on the site, nothing is replaced. That file is not imported and its result says so; import it again with another name. A page's name cannot contain `/ \ # ? % " < > | *`, and a file's name cannot contain `/` or `\`.
- When an original is kept in your encrypted vault, it is kept while you upload, so the vault must be unlocked then. If it cannot be kept, for example because the vault is locked, the import is refused, the page says why, and nothing is imported. Once the import has started you can sign out; it finishes without you.
- Only you see your imports. __Your recent imports__ lists your most recent files, newest first, and is still there after the site restarts. The site's administrator sets how many it shows.
- When you import into an encrypted vault, such as your health records, you see your file names on this page, but they are not written into the site's logs or notices, and are not shown on its administration pages.
- The page shows how many files and how much data one import can take. Put many files in a zip to bring them in together.
