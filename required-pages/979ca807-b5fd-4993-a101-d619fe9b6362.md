# Importing Files

The [Import|/import] page brings files from outside into [{$applicationname}]: documents that become pages, files for the site's file store, or records an add-on keeps, such as health records.

## What you can import into

The page lists only what your account may add to. If you may create pages, you see __Pages__. If you may upload files, you see __Files__. Add-ons can add their own, such as __Health records__. Each one decides for itself whether you may use it, with the same rules that apply anywhere else on the site.

If the page says there is nothing you can import into, your account cannot add any of these. Ask an administrator if you think it should.

A link from another page can open the Import page with one choice already picked, for example from your health records.

## How to import

- 1 Choose what to import into.
- 2 Choose one or more files, or a zip of them. A zip is unpacked for you; system files inside it, such as `.DS_Store`, are skipped.
- 3 Where it is offered, choose what happens to the original file: not kept, a note on what you imported saying where it came from, or a copy kept beside it.
- 4 Select __Import__.

The import runs in the background. You can leave the page; each file's result shows under __Your imports__ when you come back.

## What each result means

%%table-striped
|| Result || Meaning ||
| Imported | Everything in the file was added |
| Partly imported | Some of it was added; the message says what was left out |
| Already imported, unchanged | You imported this same file here before, so it was skipped |
| Already here | What the file holds is already on the site, for example a page with the same title |
| Skipped (not content) | A system file, such as one a computer adds to a zip |
| Could not be read | The file is not in a format this choice can read |
| Not allowed | Your account may not add this |
| Failed | Something went wrong; the message says what |
/%

## Good to know

- Importing the same file again does not add it twice.
- Only you see your imports. The list keeps your recent imports until the site restarts.
- The page shows how many files and how much data one import can take. Put many files in a zip to bring them in together.
