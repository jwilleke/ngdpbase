# App Health

Deterministic data-quality audit of this instance — **orphan pages**, **broken / undefined links**, and **stale pages**. Generated on demand from data the platform already has; nothing is stored or cached.

Tune with plugin parameters, e.g. `[{AppHealthPlugin staleDays='30'}]` for a meaningful stale view on instances whose pages were recently re-stamped, or `[{AppHealthPlugin format='count'}]` for a one-line summary. Parameters: `checks`, `staleDays`, `max`, `include`, `exclude`, `format` (see `docs/plugins/AppHealthPlugin.md` in the repo).

[{AppHealthPlugin}]
