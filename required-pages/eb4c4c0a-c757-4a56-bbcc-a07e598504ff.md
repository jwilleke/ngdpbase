# Page Attachments

The __Page Attachments__ section on the edit form lets you upload files to a page and insert references to them in the page content.

## Uploading a File

1. Click __Upload__ in the Attachments section
2. Select a file from your computer
3. The file is attached to the current page

## Inserting an Attachment into Content

Once a file is uploaded, two buttons appear in the attachments table:

%%table-striped
|| Button || What It Does ||
| __Insert__ | Inserts `[{ATTACH src='filename'}]` markup at your cursor position in the content editor |
| __URL__ | Copies the file's direct URL to the clipboard |
/%

The `[{ATTACH src='filename'}]` plugin renders the attachment inline when the page is viewed — images display as images, other files as download links.

## Browse Assets

Click __Browse Assets__ to open the media library and insert images or files from the shared asset pool rather than uploading a new file.
