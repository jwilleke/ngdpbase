# System Category

The __System Category__ classifies a page by its role in [{$applicationname}]. It controls where the page is stored and how the system treats it.

Only __administrators__ can set or change a page's System Category. Everyone else sees it as a read-only field: a page they create is `general`, a page they edit keeps the category it has, and a request for any other category is refused.

## Categories

%%table-striped
|| Category || Stored || Description ||
| `general` | `vault` | General pages. Default for new pages. Can be private, in the author's own vault. |
| `system` | `public` | System configuration and infrastructure pages. Needed for platform operation. Listed on [System Pages]. |
| `documentation` | `public` | End-user help and guides. Listed on [User Documentation]. |
| `developer` | `none` | Developer documentation and technical notes. Not visible on the platform — GitHub source only. Links are in [Documentation for Developers]. |
| `addon` | `public` | Pages seeded by an installed add-on. |
/%

## Where Pages Are Stored

Each category says where its pages are stored, shown in the __Stored__ column:

%%table-striped
|| Stored || What it means ||
| `none` | Never stored on the platform. Its pages live only in the source tree, so saving one is refused. |
| `public` | Stored in the shared pages folder. Its pages can never be private. |
| `vault` | Stored in the shared pages folder, and a page can also be private: it then lives in its owner's own vault for that category. |
/%

## Current Values

[{ConfigAccessor type='systemCategories' enabled=true}]

To list only some, filter on where they are stored, for example `[{ConfigAccessor type='systemCategories' stored='vault'}]`.

## Why It Matters

Pages that ship with [{$applicationname}] (the `system` and `documentation` pages) or with an add-on are copied onto the platform once, when they first appear. Only administrators can edit, rename or delete them, and they can never be private. An administrator can bring a copy back in line with the release from Admin › Required Pages Sync; a copy edited on this site is marked as edited and is left alone unless the administrator chooses to overwrite it. Whether a page is such a copy is decided for each page, so a `system` page created on this site is not treated as a shipped one.

Pages in a category stored as `none` never appear on the platform at all.

Changing the category of an existing page may affect whether it can be private and whether it is listed in Required Pages Sync.
