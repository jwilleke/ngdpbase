# Page Information

__Page Information__ is available from the __Info__ dropdown in the toolbar. It opens a modal showing the current page's metadata.

## What It Shows

|| Field || Description ||
| Title | The page's display name |
| Page Name | The internal name used in URLs |
| Slug | The URL-friendly identifier |
| UUID | The page's unique system identifier |
| Version | Whether the page is versioned |
| URL | The direct link to the page |
| Created | Date and time the page was first created |
| Last Modified | Date and time of the most recent save |
| Last Accessed | Date and time of the most recent view |
| Author | The user who originally created the page, shown as their username followed by their id |
| Editor | The user who saved the latest version, shown the same way |
| Category | The [System Category] of the page |

## How People Are Named

Every account has a username, which is what you sign in with, and an id that never changes, such as `urn:uuid:3f6c2a9e-…`. Wherever the site names who wrote or changed a page or uploaded a file, it shows both: `jim (urn:uuid:3f6c2a9e-…)`. The username is what you know them by; the id is what tells two accounts apart, even if one of them later has the same username as an earlier one.

When the account that wrote a page no longer exists, the page shows the old username followed by `(no account)`, for example `bob (no account)`. Nobody can act as the author of such a page, not even a new account that takes the same username; an administrator can.

The same naming is used in [Page History], [Recent Changes], your own page lists and the trash.
