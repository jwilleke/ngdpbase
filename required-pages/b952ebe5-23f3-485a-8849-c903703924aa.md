# Maintenance Mode

__Maintenance Mode__ temporarily restricts access to [{$applicationname}] for non-administrator users. While active, regular users see a maintenance notice instead of normal content. Administrators retain full access and can continue working normally.

Maintenance mode stays on across a server restart until an administrator turns it off.

[{$applicationname}] can also put itself in maintenance mode when something it needs is not working, such as its database or a required add-on. Then everyone, administrators included, can only sign in and use the Admin Dashboard until the problem is fixed and the server restarted. The Admin Dashboard lists why the site is in maintenance mode.

## When to Use Maintenance Mode

- Performing a large import or export
- Running a manual reindex on a heavily loaded system
- Applying configuration changes that require a brief period of restricted access
- During scheduled database or file system maintenance

## Enabling Maintenance Mode

1. Go to __Admin Dashboard__
2. Click __Enable Maintenance__ in the Administrative Tools panel
3. Confirm the action when prompted

A warning banner is shown on the Admin Dashboard while maintenance mode is active.

## Disabling Maintenance Mode

1. Go to __Admin Dashboard__
2. Click __Disable Maintenance__
3. Confirm the action when prompted

Users can access the platform again immediately after maintenance mode is disabled.

## What Visitors See

Visitors see a maintenance page named after the site, with a message and, if one is set, how long it is expected to take. They never see why the site is in maintenance mode. An administrator sets both on the Configuration screen:

| Setting | What it is |
|---|---|
| `ngdpbase.features.maintenance.message` | The message visitors see. Any text |
| `ngdpbase.features.maintenance.estimated-duration` | How long it is expected to take, for example "about an hour". Empty shows nothing |
| `ngdpbase.features.maintenance.allow-admins` | Whether administrators may use the whole site while an administrator has turned maintenance mode on |

## Behavior During Maintenance

- Regular users visiting any page see a maintenance notice with no page content
- Administrators see the platform normally with a banner indicating maintenance mode is on
- API requests from non-administrators receive an HTTP 503 response
- The server log records when maintenance mode is enabled and disabled

## Notes

- Maintenance mode does __not__ stop background processes (scans, indexing, etc.)
- There is no scheduled maintenance mode; it must be toggled manually
