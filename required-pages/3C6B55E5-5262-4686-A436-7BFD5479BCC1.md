# Using SessionsPlugin

The __SessionsPlugin__ displays the number of active user sessions. It can show either total sessions or distinct logged-in users. See [Plugins] for a complete list of available plugins.

## Syntax

[[{SessionsPlugin}] renders as:

[{SessionsPlugin}]

## Parameters

%%table-striped
|| Parameter || Type || Default || Description ||
| `property` | string | `users` | What to count: `users` (total sessions) or `distinctUsers` (unique logged-in users) |
/%

## Examples

### Total sessions

[[{SessionsPlugin}] active sessions.] renders as:

[{SessionsPlugin}] active sessions.

### Distinct logged-in users

[[{SessionsPlugin property='distinctUsers'}] unique users online.] renders as:

[{SessionsPlugin property='distinctUsers'}] unique users online.

## How Often It Updates

Pages are kept ready in memory between views. A page that shows the session count is brought up to date at most once a minute, so the number can be up to a minute behind.
