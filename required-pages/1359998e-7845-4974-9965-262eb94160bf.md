# Using PageSlideshowPlugin

The __PageSlideshowPlugin__ shows a rotating set of pages on any page: each slide has the page's title, the start of its text and a __Read more__ link to the page.

## Description

Use it for a front-page banner of featured pages, a "did you know" panel, or a tour of a topic. Name the pages to show, or ask for a few at random. For a slideshow of pictures, see [Using SlideshowPlugin]. See [Plugins] for every plugin.

## Who sees which slides

Each slide is a page, and a page only appears for people who may read it:

- A private page, or a page whose audience leaves someone out, is skipped for that person. Their slideshow simply has fewer slides.
- Someone who is not signed in sees only the pages anyone may read.
- With `random`, pages are drawn only from those the person looking may read.
- When nobody can be shown a slide, the plugin says so instead of showing an empty frame.

So you can safely name a private page: its owner sees it, and nobody else learns it exists.

## Syntax

[[{PageSlideshowPlugin pages='Using SlideshowPlugin,Markdown as we use it'}] renders as:

[{PageSlideshowPlugin pages='Using SlideshowPlugin,Markdown as we use it'}]

## Parameters

%%table-striped
|| Parameter || Default || Description ||
| `pages` | *(none)* | Comma-separated page names to show, in order. Use this or `random`. |
| `random` | *(none)* | How many pages to pick at random from those the reader may read. |
| `interval` | `5000` | Milliseconds between slides. `0` turns autoplay off. |
| `excerpt` | `300` | Most characters of each page's text to show. |
| `showTitle` | `true` | Show the page title on each slide. |
| `showLink` | `true` | Show the __Read more__ link. |
| `controls` | `true` | Show the previous and next arrows. |
| `indicators` | `true` | Show the row of slide dots. |
| `height` | `300px` | Smallest height of each slide (any CSS length). |
| `cssclass` | *(none)* | An extra CSS class on the slideshow, for your own styling. |
/%

## Examples

### Three random pages, slower

[[{PageSlideshowPlugin random='3' interval='8000'}] renders as:

[{PageSlideshowPlugin random='3' interval='8000'}]

### Short excerpts, no arrows, no autoplay

[[{PageSlideshowPlugin pages='Using SlideshowPlugin,Markdown as we use it' excerpt='120' controls='false' interval='0'}] renders as:

[{PageSlideshowPlugin pages='Using SlideshowPlugin,Markdown as we use it' excerpt='120' controls='false' interval='0'}]

## Notes

- A page name that does not exist is skipped, the same as one the reader may not read.
- Several slideshows can sit on one page; each runs on its own.
