# Demo Sandbox

__Edit this page.__ That is what it is for. You cannot break anything that matters.

If you have not signed in yet, see [Demo Welcome] — it takes one email and no password.

## Things worth trying

Click __Edit__, change something, save, and see what happens.

- Add a heading and watch it appear in the page outline
- Make a list, a table, a code block
- Link to another page with `[Demo Welcome]`
- Link to a section with `[Demo Feature Tour#tables]`
- Save twice, then open __History__ and compare the versions
- Roll a change back and watch the version count grow rather than shrink
