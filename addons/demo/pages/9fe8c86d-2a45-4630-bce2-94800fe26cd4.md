# Demo Welcome

This is a **public demo** of ngdpbase. Everything here is real software — the same build anyone can run — pointed at a throwaway data volume.

Read anything without signing in. To try **editing**, you need an account.

## Getting an account

Sign in with your **email address**. No password is involved, and none is ever created for you:

1. Go to the sign-in page and enter your email.
2. A one-time link arrives in your inbox.
3. Click it. That's it — you're in, and an account is created on first use.

The link expires after a few minutes and works once. If it expires, request another.

Accounts made this way have **no password at all**, so there is nothing to forget and nothing to leak.

## What you can do once signed in

- **Edit** any existing page
- **Create** new pages
- **Upload** attachments and media

What you cannot do is delete or rename pages. That is deliberate — a shared demo where anyone can delete anything does not stay useful for long.

## Please read before you write

> **Treat everything here as disposable.** This is a demo, not a hosting service. Nothing is backed up, the site can be reset to a clean slate at any time, and anything you write may be removed without warning. Do not put anything you want to keep on this instance — and do not put anything private, personal, or confidential on it either, because every page is world-readable.

The [Demo Sandbox] page exists specifically for experimenting. Start there.

Yes. This is not a mock-up or a limited trial — it is a normal instance with the demo settings turned on. The differences from a private install are only these: registration is by email link only, edits are limited to creating and changing pages, and the data is disposable.
