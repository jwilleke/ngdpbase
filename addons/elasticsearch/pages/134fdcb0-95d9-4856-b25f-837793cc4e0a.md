# External Asset Search

External Asset Search lets you find and insert files indexed from external storage (NAS, S3, or any Elasticsearch-indexed source) directly from the wiki editor — photos, documents, videos, and more.

## Using the Asset Browser

When editing a page, click the __Insert Asset__ button (paperclip icon) in the toolbar. The asset browser opens and shows files from all sources including the external asset index.

Use the __Source__ filter to select __External Asset Index__ to show only externally indexed files.

## Searching for Files

Type in the search box to find files by:

- __Filename__ — partial matches work (`vacation` finds `summer-vacation-2023.jpg`)
- __Path__ — folder names on the NAS (`family/photos`)
- __Content__ — text extracted from documents and images (OCR)
- __Tags__ — labels assigned to files

### Filtering Results

| Filter | What it does |
|--------|-------------|
| Type | Limit to Images, Documents, or Other |
| Year | Filter by file modification year |
| Sort | Date modified (newest first) or filename A–Z |

## Inserting a File

Click any result to preview it. Click __Insert__ to add it to your page. Image files are inserted as:

```
[{Image src='...'}]
```

Other files are inserted as a link to the full file.

## Thumbnails

Images and some document types show a thumbnail preview. If a thumbnail is not yet available the file was recently added and sist2 is still processing it — try again shortly.

## What Files Are Available

The external asset index includes files from storage scanned by sist2 (NAS, S3, or other configured sources). Your administrator controls which folders are visible based on your account role.

## Frequently Asked Questions

__Can I upload files from here?__
No. The external asset source is read-only. Use your normal file manager or storage client to add files — they will appear in the wiki after the next scheduled scan.

__How current is the index?__
Storage is scanned automatically on a schedule (typically nightly). Files added during the day will appear after the next scan. Ask your administrator to trigger a manual scan if you need a file to appear sooner.

__I found a file but can't see its thumbnail.__
Thumbnails are generated progressively. If the file was recently indexed the thumbnail may not exist yet. The full file is always available via the link.

__Why can't I see a folder I know exists?__
Access to NAS folders is controlled by your account role. Contact your administrator if you believe you should have access to additional folders.
